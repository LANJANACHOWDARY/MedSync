# MedSync

MedSync is a **healthcare web application** connecting hospitals, NGOs, and donors, enabling efficient management of hospital requests and donation workflows.

---

## Features
- Hospitals can create requests for blood, medicines, or other resources.  
- NGOs and donors can view hospital requests and contribute.  
- Streamlined coordination of donation requests and approvals.  
- User login and dashboard functionality for hospitals, donors, and NGOs.

---

## Technology Stack
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Node.js (without frameworks)  
- **Database:** MySQL
